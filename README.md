# Student Chatbot — Campus Regulations Assistant

A Retrieval-Augmented Generation (RAG) assistant that answers students' questions
about college regulations using **only** the official documents, with source
citations, and declines questions the documents do not cover.

This is **Theme 2A** of the HackDay. Full brief: [`ps-theme2.md`](ps-theme2.md).

- **Answers:** Gemma 4 (`gemma-4-26b-a4b-it`) via the free Google AI Studio API — no GPU needed.
- **Retrieval:** `all-MiniLM-L6-v2` embeddings (runs on CPU).
- **Documents:** PDFs in [`dataset/`](dataset/).

## Dev setup

```bash
git clone https://github.com/manyatha-313/student-chatbot
cd student-chatbot

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # then paste your key into .env
```

Get a free `GOOGLE_API_KEY` at https://aistudio.google.com/apikey (one per team
member is recommended, to share the free-tier limits). Without a key the retrieval
still works; it shows the passages it found in place of a written answer.

The first run downloads the embedding model (a few minutes).

## Run

The assistant reads the prebuilt chunks in `dataset/processed/chunks.jsonl`
(generated by `scripts/prepare_dataset.py`); if that file is absent it chunks
the PDFs in `dataset/` directly.

- **Web app (the campus_assistant_frontend.html page):** `python serve.py`
  then open http://localhost:8000. The page calls `POST /ask` with
  `{"question": "..."}` and gets back `{"answer", "sources": [...]}`.
- **Gradio app (alternative UI):** `python app.py` (prints a public link).
- **Quick check:** `python rag.py` (sample Q&A); `python eval/eval.py`
  (retrieval / keyword / refusal metrics).
